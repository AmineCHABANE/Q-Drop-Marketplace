The Bundle

5 modules, 5 fundamental algorithms

Each one is the core algorithm of a production system you already use — stripped down to a few hundred readable, commented lines.

Q-HNSW

src/q_hnsw.py

Hierarchical Navigable Small World graph for approximate nearest-neighbor vector search — the published algorithm (Malkov & Yashunin 2018) used by every major vector database.

PineconeQdrantPython

Q-LSM

src/q_lsm.py

Log-Structured Merge-tree storage engine: write-ahead log, MemTable, SSTables, k-way merge compaction, and tombstone deletes — the architecture of RocksDB and Cassandra.

RocksDBCassandraPython

Q-COL

src/q_col.py

Columnar analytics engine with bitmap filter masks, hash-based GROUP BY, dictionary encoding, and run-length encoding — how DuckDB and Arrow process analytical queries.

DuckDBArrowPython

Q-STREAM

src/q_stream.py

Windowed stream processor implementing the Dataflow model: tumbling, sliding and session windows, watermarks, and late-event handling — the concepts behind Kafka Streams and Flink.

Kafka StreamsFlinkPython

Q-MEM

src/q_mem.py

Arena allocator with jemalloc-style size classes, slab carving, O(1) LIFO free lists, and live fragmentation statistics — the memory model of allocators and game engines.

jemallocAPR poolsPython
